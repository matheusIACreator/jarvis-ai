# 0007 — Python 3.12 no ambiente de desenvolvimento

## Contexto

- O `pyproject.toml` exige Python `>=3.11`.
- Na máquina estão instalados Python 3.12 e 3.14; o 3.11 não está.
- O projeto vai depender de bibliotecas de áudio e ML (faster-whisper/ctranslate2, captura de áudio) que costumam demorar a publicar wheels para Windows em versões novas do Python.

## Decisão

- A `.venv` usa Python 3.12: `py -3.12 -m venv .venv`.
- `requires-python` continua `>=3.11`.
- pytest como dependência opcional de desenvolvimento: `pip install -e ".[dev]"`.

## Alternativas consideradas

- **Python 3.14** — já instalado como padrão, mas alto risco de faltar wheels para as libs de áudio/ML no Windows.
- **Instalar Python 3.11** — funcionaria, mas não traz vantagem sobre o 3.12 já instalado.

## Consequências

- Instalação das futuras dependências mais previsível no Windows.
- Ao chamar `python` sem a `.venv` ativa, o Windows usa o 3.14; sempre ativar a `.venv` ou usar `.\.venv\Scripts\python.exe`.
